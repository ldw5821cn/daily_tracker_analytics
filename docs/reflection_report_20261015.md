### 问题 1: 补仓计算错误

**现象**: 建议 500 元买 400 股平安银行

**实际**: 500 元只能买 44 股，不够 100 股最小单位

**原因**: 
- 忽略 A 股最小交易单位 100 股
- 计算时未做校验

**影响**: 
- 用户质疑
- 信任度下降

**修复**: 
- 立即承认错误
- 重新计算正确股数

**改进措施**:
```
补仓计算时自动校验:
  lot_size = 100  # A股最小单位
  max_shares = int(budget / price / lot_size) * lot_size
  if max_shares < lot_size:
      return "资金不足最小交易单位"
```

## 四、优化建议

### 优化 1: 补仓计算自动校验

**当前问题**: 手动计算，容易出错

**优化方案**: 
```python
def calculate_shares(budget, price, lot_size=100):
    """计算可买股数，自动校验最小交易单位"""
    shares = int(budget / price / lot_size) * lot_size
    if shares < lot_size:
        return {
            'shares': 0,
            'message': f'资金不足，{budget}元无法购买{lot_size}股',
            'min_budget': price * lot_size
        }
    return {
        'shares': shares,
        'cost': shares * price,
        'message': f'可购买 {shares} 股，花费 {shares * price:.2f} 元'
    }
```

**实施优先级**: 高
