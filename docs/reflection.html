## 4. 数据驱动改进建议（禁止硬编码）

核心思路：把"资金行为 + 证据完备度 + 背离方向"变成可学习特征，让 optimizer 自己发现退潮期该降权技术面。

1. 扩展历史标签仓库：积累 60-90 天真实收益标签，让 optimizer 在中分区间（45-60）有足够样本学习"高分≠看多"的映射。
2. 新增特征入 feature_snapshot（不设阈值）：
- `fundamental_technical_divergence`（正式纳入，允许学习符号与交互项）
- `evidence_balance = bull/(bull+bear)`、`bear_evidence_count`（学习"单边证据→降权"）
- `confidence_calibration_error`（历史同分位实际胜率）
- `market_breadth`（涨跌家数比、涨停/跌停比）
- `northbound_flow_zscore`、`margin_balance_change`、`option_pcr`
- `sector_rotation_strength`（周期→防御轮动强度）
3. 样本权重机制：时间衰减权重 + 类别平衡权重（看多样本当前被过度代表，应降权），由 optimizer 自动学习。
4. 置信度重校准：用 isotonic regression / Platt scaling 对 confidence 做后处理，让 0.66 真实反映 ~66% 胜率。
5. 补齐基本面真实值：失败 Top5 中 4 条基本面默认填 50（中性噪声），需回补个股基本面/资金面真实值，避免默认值污染。
