## 2. 主要错误模式

### 模式一：中性信号"沉默性失明"——低分标的隐藏重大利好（61/91错，错误率67%）

量化证据：错误中性样本中，新闻情绪得分56.33 vs 正确样本54.12，且多空辩论净得分-0.98 vs 正确样本-0.14。失败样本Top 5中，东方钽业、华工科技、光智科技、澜起科技、翱捷科技全部为中性信号，但新闻情绪均为正（+0.16~+0.42），多空辩论却给出看跌2-3票的压制。

A股归因：这些标的多为科技成长股（半导体、激光、新材料），在政策催化或产业趋势驱动下，新闻情绪领先于技术面。技术面评分42-52分处于"中性偏弱"区间，但新闻面已释放积极信号。A股散户主导的市场中，消息驱动的脉冲式上涨往往先于技术指标突破——涨停潮、龙虎榜游资进场、板块联动效应都是技术面尚未反映的领先信号。系统将新闻正面信号与辩论看跌票简单加权后归为"中性"，实质是把信息优势当噪声丢弃。

Thesis Breakers（证伪触发器）：若此类标的技术面在3-5个交易日内未跟随新闻面转强（如MACD未金叉、成交量未放大至5日均量1.5倍以上），则新闻情绪可能为"利好出尽"型噪声，中性判断成立。

### 模式二：看空信号"逆势踏空"——空头逻辑在强势趋势中失效（5/7错，错误率71.4%）

量化证据：看空错误样本平均fund-tech背离+5.60，说明基本面强于技术面时系统仍给出看空信号。结合知识库中[FIXED] debate_hard_floor_2026-08-09的教训——tech_score低时强制bear_score≥1.0——旧有硬编码虽已修复，但debate_engine中tech_score对bear_score的soft prior影响可能仍然过强。

A股归因：A股市场强者恒强效应显著，尤其在产业趋势明确的板块（如AI算力、新能源、军工），技术面"超买"或"高位"并不构成做空理由。政策扶持+产业逻辑+资金抱团三重驱动下，基本面强势标的可以长期无视技术面回调信号。此外，涨停制度下强势股往往以连续涨停方式完成主升浪，技术指标持续钝化，看空信号在T+1制度下不仅无法获利，还可能因次日高开而承受更大损失。

Thesis Breakers（证伪触发器）：看空信号成立需同时满足——a) 基本面/新闻面转弱（如业绩预告下修、行业政策收紧）；b) 资金面撤离（北向连续3日净卖出、两融余额下降）；c) 技术面跌破关键支撑（如20日均线且放量）。三者缺一不可，否则看空信号应降级为中性。

### 模式三：期货信号相对较好但仍有提升空间（20/49错，错误率40.8%）

期货错误率显著低于股票/ETF，说明期货的宏观/商品基本面因子相对有效。但40.8%的错误率仍意味着近半数预测偏差，且期货杠杆高，错误代价被放大。错误样本中宏观信号均为neutral/54.6，宏观因子区分度不足——在宏观环境模糊期，系统缺乏对商品供需微观结构的感知能力。

## 4. 数据驱动改进建议

### 4.1 新增特征维度（供parameter_optimizer自动学习）

| 新增特征 | 说明 | 预期解决的问题 |
|---------|------|--------------|
| 新闻情绪趋势斜率 | 新闻情绪3日/5日变化率，而非仅当前值 | 区分"持续发酵"与"一次性脉冲" |
| 新闻情绪与价格背离 | 新闻正面但价格未涨的背离度 | 捕捉"信息尚未被定价"的机会 |
| fund-tech背离方向强度 | 将背离值按方向分桶（正/负/零）并量化强度 | 让优化器学习不同背离方向的含义 |
| 板块动量 | 所属行业指数5日/20日涨幅排名 | 捕捉A股板块轮动效应 |
| 涨停/跌停家数市场宽度 | 当日全市场涨停vs跌停家数比 | 反映市场风险偏好与情绪周期 |
| 北向资金个股持仓变化 | 北向资金近5日净买入/卖出 | 捕捉外资增量资金动向 |
| 两融余额变化率 | 个股融资余额5日变化率 | 反映杠杆资金风险偏好 |
| 龙虎榜活跃度 | 是否上榜、净买入额、游资席位特征 | 捕捉散户情绪与游资动向 |
| 成交量异常度 | 当日成交量/5日均量的比值 | 捕捉放量突破或缩量见顶信号 |
| 宏观因子细分 | 将宏观信号拆分为流动性/政策/经济周期子项 | 解决宏观因子区分度不足问题 |

### 4.2 数据仓库扩展方向

- 积累30-60天真实标签：当前系统处于学习期，需持续积累"预测→实际收益"配对数据，让优化器有足够样本学习权重映射
- 引入TickFlow日内数据：减少滞后技术面影响，捕捉盘中资金流向变化
- 建立A股特色事件库：政策发布、监管函、业绩预告、股权变动等事件的标准化标注数据
