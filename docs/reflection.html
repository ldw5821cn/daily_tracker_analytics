## 2. 主要错误模式

### 错误模式一：基本面-技术面背离时，系统"骑墙"错失大牛股（最严重）

量化证据： 失败样本 Top 5 中，东方钽业（收益+6576%）、顺络电子（+6.77%）、唯特偶（+4.84%）全部为"信号中性"，但基本面分别达58/70/62，新闻情绪全部为正（+0.34/+0.20/+0.40）。而看多错误样本的平均背离度高达 10.06（n=37），远高于中性错误的8.07。

A股归因： 东方钽业属于稀有金属板块，2026年正值战略小金属政策催化期，此类标的往往先由政策/事件驱动启动，技术面指标严重滞后。系统在技术面52分（中性）时不敢发看多信号，但A股散户主导的行情中，政策题材一旦点燃，连续涨停板使技术指标永远"来不及"确认。这正是"政策市"特征的典型体现——基本面/消息面领先，技术面滞后。

证伪方式与监控触发器：
- 看多信号被证伪的路径： 若系统发出看多信号，需监控以下触发器——① 涨停板次日溢价率是否转负；② 龙虎榜买方席位是否以机构为主（若纯游资接力，持续性存疑）；③ 板块涨停家数是否从峰值回落超过50%。
- 中性信号被证伪的路径： 若系统发出中性信号，需监控——① 该标的是否连续3日出现主力净流入>5000万；② 所属板块涨停家数是否连续2日排名全市场前3；③ 新闻情绪得分是否连续3日>+0.3。任一条件触发，即说明中性信号错误，应回溯修正。

### 错误模式二：高置信度看多信号在宏观中性环境下失效

量化证据： 山东黄金（置信度0.84，评分70.9，基本面82，多空辩论看涨1.7 vs 看跌0）仍录得-5.42%亏损。这是全样本中置信度最高的失败案例。正确样本与错误样本的 confidence 几乎无差异（0.68 vs 0.69），说明置信度本身不携带区分能力。

A股归因： 山东黄金作为黄金股，其走势与COMEX金价、人民币汇率、美债实际利率高度相关。当前宏观信号为 neutral/50.6，但宏观Agent仅覆盖国内宏观指标，缺乏对全球流动性/美元指数的独立监控。2026年8月若美联储政策预期反复，黄金股会先于国内宏观数据做出反应。此外，北向资金在黄金股上的持仓变动往往领先股价3-5个交易日，系统缺少该维度数据。

证伪方式与监控触发器：
- 看多信号被证伪的路径： 若系统发出看多信号，需监控——① COMEX黄金期货是否跌破20日均线；② 美元指数是否连续3日走强；③ 北向资金对该标的持仓是否连续2日净卖出。任一触发即重新评估。

### 错误模式三：高评分+高基本面支撑的看多信号仍亏损——"利好出尽"型回落

量化证据： 大唐发电（评分59.7，基本面86，新闻情绪+0.45）录得-6.36%亏损。基本面优秀但股价下跌，说明市场已提前定价该利好。

A股归因： 大唐发电属于电力板块，2026年电力市场化改革预期已持续发酵。当基本面评分达到86时，往往意味着利好已被市场充分认知，股价已处于阶段性高位。A股散户主导的市场中，"利好出尽是利空"的现象尤为显著——当新闻情绪一致看多（+0.45）时，反而可能是短期顶部信号。此外，两融余额若在股价高位快速增加，往往预示杠杆资金接盘，后续回调概率大。

证伪方式与监控触发器：
- 看多信号被证伪的路径： 若系统发出看多信号，需监控——① 该股融资余额是否在5日内增加超过流通市值1%；② 新闻情绪得分>+0.4且股价已连续5日上涨；③ 换手率是否突然放大至前期均值2倍以上。任一触发即重新评估。

## 4. 数据驱动改进建议

### 4.1 新增历史数据采集

| 数据类别 | 具体字段 | 用途 |
|---------|---------|------|
| 板块/行业数据 | 申万一级/二级行业日涨幅、板块内涨停家数、板块成交额占比 | 捕捉板块beta效应，让优化器学习板块动量对个股信号的加权 |
| 北向资金数据 | 个股北向持仓变动、北向净买入额（日频） | 捕捉外资定价权，尤其对黄金、核心资产类标的 |
| 两融数据 | 个股融资余额变动、融资买入额/成交额占比 | 捕捉杠杆资金行为，识别"融资盘接盘"风险 |
| 龙虎榜数据 | 机构席位净买入、游资席位活跃度、上榜原因 | 捕捉A股特有的资金结构信号 |
| 涨停/炸板数据 | 涨停家数、炸板率、连板高度、涨停封单额 | 衡量市场情绪温度，作为市场上下文Agent的输入 |
| TickFlow日内数据 | 逐笔委托方向、大单净流入、委买委卖压力 | 减少滞后技术面影响（历史建议中已多次提及） |

### 4.2 新增因子/特征

- fund_tech_divergence_ratio：`(fundamental_score - technical_score) / 100`，作为连续特征输入优化器，让模型自动学习背离度与信号方向的关系，而非人工设定阈值
- 板块动量因子：`板块5日涨幅 - 全市场5日涨幅`，捕捉相对强弱
- 新闻情绪持续性：`新闻情绪得分5日移动平均` 及 `情绪得分标准差`，区分"持续利好"与"脉冲式利好"
- 北向资金流向因子：`北向持股变动率`（5日）
- 两融余额变动率：`融资余额5日变动百分比`
- 市场情绪温度计：`全市场涨停家数/炸板率` 作为市场上下文Agent的补充输入

### 4.3 优化器自动学习方向

- 将上述因子全部加入 `feature_snapshot`，由 `parameter_optimizer` 自动学习各因子在不同宏观/市场状态下的最优权重
- 特别关注：让优化器学习 `fundamental_score` 与 `technical_score` 的动态权重比——在板块动量强时，应给予基本面/情绪更高权重；在板块动量弱时，应给予技术面更高权重
