## 2. 主要错误模式

### 模式一：宏观偏空环境下的"基本面幻觉"——高基本面分≠可做多

量化证据： 错误样本基本面分项平均69.31，显著高于正确样本的62.87（+6.44分）；同时宏观分项全部为43.5（bearish）。fundamental_technical_divergence在错误样本中高达11.09，是正确样本（5.95）的1.86倍。

A股归因： 2026年8月市场处于宏观紧缩+情绪退潮期，基本面利好（如绿的谐波70分、柯力传感70分）无法对冲系统性下行。A股散户主导的市场中，宏观流动性收缩时，基本面因子beta暴露远大于alpha贡献——"好公司"在弱市中照样跌。错误看多样本（绿的谐波-18.59%、通富微电-10.63%）均呈现"基本面良好+技术面中性+宏观偏空"的组合，本质是系统把"公司好"误判为"股票会涨"。

Thesis Breaker（可证伪触发器）： 当宏观分项<45（bearish）且fund-tech背离度>10时，任何看多信号应视为"高风险看多"，其成立前提是个股必须出现独立于大盘的放量突破（成交量较20日均量放大1.5倍以上且涨幅>3%） 。若信号发出后3个交易日内未出现该确认，则看多逻辑自动证伪。

### 模式二：多空辩论"假均衡"掩盖真实风险——看跌证据被低估

量化证据： 错误样本多空辩论净得分-0.17，显著高于正确样本的-0.36。失败样本中，光迅科技（看涨0.2 vs 看跌1）、柯力传感（看涨0 vs 看跌1）均出现辩论结果偏空但最终信号为观望/中性，说明看跌证据未被充分转化为信号权重。

A股归因： A股做空机制受限（融券成本高、券源少），多数投资者天然偏多思维。当辩论引擎给出看跌证据时，系统未充分上调其权重——这类似于A股"利空出尽"的惯性思维，但在下跌趋势中，看跌证据的边际信息量远大于看涨证据。错误样本中"看涨1 vs 看跌1"（绿的谐波）被判定为均衡，实际在宏观偏空背景下，看跌证据应获得更高权重。

Thesis Breaker： 当宏观bearish且多空辩论中看跌证据≥1条时，信号应至少下调一档（看多→观望，观望→中性/看空）。触发监控：辩论引擎中看跌论据的事实密度（引用具体数据/事件的条数）是否被纳入权重计算。

### 模式三：技术面"中性"陷阱——48-52分区间是错误高发带

量化证据： 失败样本Top5中，4个技术面评分落在48-52区间（中性），但实际收益-10%至-18%。技术面中性≠方向不明，在宏观偏空时，技术面中性应被解读为"无支撑"而非"方向待定" 。

A股归因： A股下跌趋势中，技术面"中性"往往意味着缺乏增量资金承接。结合散户主导特征，中性区间在弱市中通常向下突破概率大于向上（散户恐慌抛售+无机构承接）。当前技术面评分公式输出大量42-55分（见知识库tech_score_distribution_bias），在宏观偏空时，这些"中性"信号实际上应该是"偏空"。

### 4.2 条件权重学习（替代硬编码）

核心思路： 不预设"宏观bearish时基本面权重应降低"这类规则，而是让优化器通过历史数据学习条件权重映射：

```
signal_score = f(tech_score, fund_score, sentiment_score, macro_score,
divergence_features, sector_features,
condition = macro_direction)
```

即：在不同宏观状态下，各因子到最终信号的映射函数f应不同。这需要：

1. 积累至少3个完整宏观周期（bull/neutral/bear各至少20个交易日）的真实标签数据
2. 将宏观状态作为条件变量而非简单加权因子
3. 让优化器自动学习：在bearish环境下，fund_score的权重是否应自动降低？debate_bear_evidence的权重是否应自动提高？

### 4.3 错误样本特征快照扩展

当前错误分析仅记录分项得分，建议扩展记录：

- 当日大盘涨跌幅（上证/创业板）
- 所属板块当日涨跌幅
- 个股成交量/20日均量比
- 当日涨停/跌停家数（市场情绪温度）
- 北向资金当日净流入
- 两融余额变化
- 个股Beta值（对大盘敏感度）

目标： 让优化器能回答"在2026-08-19这种宏观偏空+情绪退潮+板块轮动的市场状态下，什么样的信号组合最可靠？"
