## 4. 数据驱动改进建议

### 4.1 历史数据扩展

| 数据类别 | 具体内容 | 用途 |
|---------|---------|------|
| 日内TickFlow数据 | 逐笔成交的大单/中单/小单流向、主动买卖盘比例、委托队列变化 | 解决技术面滞后问题，让优化器学习"日线中性+日内资金流入"的组合模式 |
| 龙虎榜数据 | 机构席位买卖、知名游资席位动向、买入/卖出占比 | 捕捉A股散户主导市场中的主力资金行为信号 |
| 涨停/炸板数据 | 每日涨停家数、炸板率、连板高度、封板资金量 | 反映市场情绪温度，作为市场上下文因子的补充 |
| 北向资金/两融数据 | 北向资金日度净流入、两融余额变化、融资买入占比 | 反映增量资金与风险偏好，补充宏观/资金面Agent的数据维度 |
| 行业政策事件库 | 产业政策发布、监管动态、行业会议纪要 | 捕捉A股政策市特征，避免宏观偏空误伤有独立政策催化的板块 |

### 4.2 新增因子建议

- 辩论强度因子：将多空辩论的总计数（看涨+看跌）作为独立特征加入，让优化器学习"低辩论强度时信号应更保守"的映射
- fund-tech背离方向因子：将背离度拆分为"基本面>技术面"和"技术面>基本面"两个方向，分别学习其在不同宏观环境下的预测能力
- 板块动量因子：同一板块内多标的信号方向一致性（如黄金板块3只同时看多），作为信号增强特征
- 宏观-行业逻辑一致性因子：宏观方向与行业逻辑方向的匹配度（如宏观偏空+黄金避险=一致，宏观偏空+成长进攻=矛盾）

### 4.3 优化器学习目标

让 `parameter_optimizer` 自动学习以下映射关系：
- 宏观偏空环境下，个股基本面/资金面多强时应该输出看多而非中性
- 技术面中性+日内资金流入的组合如何影响最终信号
- 辩论强度低时置信度应如何校准
