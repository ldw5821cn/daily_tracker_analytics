Thesis Breakers（可证伪触发器）：
- 若宏观分 < 50 且市场上下文 = neutral，则看多信号应被视为低置信候选，需额外证据（如北向资金连续净流入、板块涨停家数占比提升）方可维持；

监控触发器： 5日累计涨幅、换手率分位数、龙虎榜买入集中度。

## 4. 数据驱动改进建议

> 核心原则： 不添加任何硬编码拦截规则、固定阈值或方向否决门。所有改进通过扩展数据维度、积累真实标签，让 parameter_optimizer 自动学习权重/阈值映射。

### 建议一：将因子背离度纳入特征快照，让优化器学习背离的真实含义

- 具体做法： 将 `fundamental_technical_divergence`、`sentiment_macro_divergence`、`debate_technical_divergence` 等背离指标作为独立特征存入 feature_snapshot，与最终收益标签关联。
- 预期效果： 优化器可自动学习"背离度在什么范围内是噪声、什么范围内是风险信号"，而非人工设定阈值。

### 建议二：建立"宏观状态 × 信号方向"的条件概率表

- 具体做法： 将历史数据按宏观状态（bullish/neutral/bearish）分层，统计不同宏观状态下各信号方向的条件胜率。让优化器自动学习"宏观偏空时，看多信号的权重应下调多少"。
- 预期效果： 解决当前"宏观偏空 + 个股基本面好 → 看多信号失效"的系统性问题。

### 建议三：引入"拥挤度"因子作为特征

- 具体做法： 将5日涨幅、换手率分位数、融资买入占比、龙虎榜净买入等A股特色拥挤度指标加入特征集。
- 预期效果： 让优化器学习"高拥挤度 + 高信号分"是否应降低看多置信度。

### 建议四：置信度校准——引入真实收益标签的 Platt Scaling

- 具体做法： 积累30天以上真实收益标签后，用 Platt Scaling 或 Isotonic Regression 对模型输出的 confidence 做校准，让置信度反映真实胜率。
- 预期效果： 解决"高置信度反而低准确率"的置信度失真问题。
