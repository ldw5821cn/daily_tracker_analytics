## 1. 一句话总结

本质原因： 看空与中性信号错误率畸高（56.8%/48.9%），核心是技术面评分系统性偏低（42-45分聚集）叠加多空辩论净得分偏负，导致模型在基本面/资金面偏多时仍给出保守或看空信号，错失上涨。


## 2. 主要错误模式

### 模式一：技术面评分系统性偏低 + 多空辩论净得分偏负 → 看空/中性信号过度保守

量化证据：
- 错误样本中技术面平均分 51.39 vs 正确样本 56.77，差距 5.38 分，为全部分项中最大差距
- 错误样本多空辩论净得分平均 -0.74（偏看跌），而正确样本为 +0.01
- 看空信号错误率 56.76%（21/37），中性信号错误率 48.94%（23/47），合计占全部错误的 62.9%

失败样本验证：
- 688082 盛美上海（信号看空，实际+12.16%）：技术面仅42分触发看空，但基本面58分、新闻情绪+0.35偏正，多空辩论看涨1 vs 看跌3——辩论引擎被低技术分钳制（已修复的 debate_hard_floor 问题可能仍有余波）
- 300666 江丰电子（信号中性，实际+9.66%）：技术面42分但基本面70分良好，新闻情绪+0.35，多空辩论看涨1 vs 看跌2——中性信号未能反映基本面强势

A股归因： 2026年8月处于有色金属/半导体材料板块的结构性行情中，板块受政策催化（如半导体国产替代政策加码、小金属出口管制等）驱动，资金面与情绪面领先于技术面。技术指标在趋势启动初期往往滞后，模型过度依赖技术面评分导致系统性踏空。

Thesis Breakers（可证伪触发器）：
- 若上述标的技术面评分持续低于45但基本面>65且新闻情绪>+0.3，应触发"技术面滞后"假设的重新评估
- 监控：当 fundamental_score - tech_score > 20 且 news_sentiment > +0.3 时，看空/中性信号的置信度应被自动降权


### 模式二：因子背离度低时模型过度自信，背离度高时反而信号模糊

量化证据：
- 正确样本 fundamental_technical_divergence 平均 10.59 vs 错误样本 8.08——背离度越高反而预测越准确
- 错误看空样本背离度仅 9.08，错误中性样本背离度 10.17，但错误观望样本背离度 -0.03（几乎无背离）
- 正确样本基本面分 67.36 vs 错误样本 59.46，差距 7.90 分——基本面分是区分正确/错误的最强单一因子

解读： 当基本面与技术面出现适度背离时（divergence 10-15区间），往往意味着基本面领先于技术面的早期机会；而当背离度过低时（<5），说明所有因子都指向"无趋势"，此时模型给出中性/观望信号但实际市场可能正在酝酿方向性突破。

A股归因： A股散户主导的市场中，情绪羊群效应常在基本面改善初期滞后反应。当基本面分高（>65）但技术面尚未跟上时，恰是主力资金提前布局的阶段。模型将这种背离视为"不确定性"而给出中性信号，实则是将alpha机会误判为噪音。

Thesis Breakers：
- 若背离度 > 15 且基本面 > 65 且新闻情绪 > +0.3，模型应倾向看多而非中性
- 监控：背离度与后续5日收益的相关性，若正相关性持续，则背离度应作为看多信号的增强因子


### 模式三：宏观/市场上下文信号钝化，无法捕捉板块轮动与增量资金方向

量化证据：
- 所有失败样本宏观分均为 49.9/100（中性），市场上下文均为 neutral(50.0/100)——宏观维度完全无法区分正确与错误样本
- 期货错误率 53.06%（26/49）显著高于ETF（26.09%）和个股（35.85%），期货对宏观/资金面更敏感，但当前宏观 Agent 未能提供有效区分

A股归因： 当前宏观 Agent 仅输出单一中性信号，无法捕捉：
- 北向资金流向：2026年8月北向资金持续净流入有色金属/半导体板块，但宏观 Agent 无此维度
- 两融余额变化：杠杆资金加仓方向未被监控
- 板块轮动效应：宏观中性不等于板块中性，当前系统缺少中观（行业/板块）层面的判断

成功样本共性：
1. 基本面分 > 65 是核心前提：成功样本基本面平均 67.36，显著高于错误样本的 59.46。基本面优秀（>70）的标的即使技术面中性，看多信号也大概率正确（如 600392 盛和资源基本面79分但信号中性，实际+6.06%——若信号为看多则正确）
2. 多空辩论净得分 ≥ 0 时看多信号可靠性高：成功看多样本（腾远钴业、中钨高新、有研新材、银泰黄金）多空辩论均偏看涨
3. 适度因子背离（10-15区间）是机会信号而非噪音：成功样本背离度 10.59，说明基本面领先技术面的早期机会反而是最佳入场点
4. 置信度 ≥ 0.70 时信号更可靠：成功样本置信度 0.71 vs 错误样本 0.68，但差异不大——置信度区分度有限，需引入更多特征


## 4. 数据驱动改进建议

### 4.1 新增特征维度（供 parameter_optimizer 自动学习）

| 新增特征 | 说明 | 预期作用 |
|---------|------|---------|
| `fund_tech_divergence_direction` | 背离方向（基本面>技术面 或 反之），而非仅背离绝对值 | 让优化器学习"基本面领先"与"技术面领先"的不同含义 |
| `debate_net_score_normalized` | 多空辩论净得分除以辩论总票数，消除票数规模影响 | 更准确反映多空力量对比 |
| `sentiment_momentum` | 新闻情绪的一阶差分（近3日变化），而非仅当前值 | 捕捉情绪改善/恶化的趋势 |
| `sector_momentum_rank` | 个股所属行业板块近5日涨幅在全行业中的分位数 | 捕捉板块轮动效应 |
| `northbound_flow_5d` | 北向资金近5日净流入（按个股所属板块聚合） | 反映增量资金方向 |
| `margin_balance_change` | 两融余额近5日变化率 | 反映杠杆资金风险偏好 |
| `turnover_volume_ratio` | 当日成交量/5日均量 | 反映资金活跃度变化 |

### 4.2 特征交互项（让优化器学习非线性关系）

- `fundamental_score × divergence_direction`：基本面分高且基本面领先时，看多信号增强
- `tech_score × sector_momentum_rank`：技术面中性但板块强势时，看多信号增强
- `debate_net_score × news_sentiment`：多空辩论与新闻情绪共振时的信号增强

### 4.3 标签优化

- 建议将收益标签改为 5日收益 + 最大回撤 的复合标签，而非仅5日收益——当前"信号看多但收益-7.03%"（翱捷科技）可能因入场时机不佳导致，但若期间有+5%以上的浮盈，信号方向可能并不完全错误
