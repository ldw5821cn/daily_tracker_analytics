## 4. 数据驱动改进建议

**4.1 建立“预测-收益”标签数据仓库**

当前系统最薄弱的环节是缺乏系统性的真实收益标签积累。建议建立每日预测结果与后续1/3/5/10日实际收益的映射数据仓库，包含完整特征快照（技术面、基本面、情绪、多空辩论、宏观、市场上下文等），使parameter_optimizer能够基于真实标签自动学习各因子的最优权重和信号阈值，而非依赖人工设定的固定规则。

**4.2 增加“基本面-情绪与技术面背离”特征**

失败样本的共性特征是“技术面中性偏弱 + 基本面良好 + 情绪为正”。建议构造**因子背离度特征**（如基本面得分与技术面得分的差值、情绪得分与多空辩论结果的偏离度），让优化器自动学习背离状态下的最优信号方向，而非由技术面单一主导。

**4.3 增加期货专属的宏观敏感性特征**

期货错误率最高（75.51%），建议为期货标的引入**宏观因子与品种类别的交互特征**（如宏观信号×品种板块、宏观信号×合约到期时间等），使优化器能够学习不同宏观环境下各期货品种的条件概率分布。
