## 2. 主要错误模式

### 模式A：看多信号系统性失效（n=10，错9，错误率90%）
三方一致指向同一病灶。看多样本平均 `fundamental_technical_divergence = -15.44`，是全部信号中最极端的负背离——技术面/辩论给出看多，但基本面锚定值远低于技术面。这不是随机噪声，而是优化器在多头方向上把权重过度分配给滞后技术面与辩论净得分，未学到"高负背离+看多=低可信"的映射。在震荡轮动市中，这类标的往往是情绪已透支、资金正在撤离的品种，追多即被套。

### 模式B：置信度机制失效（校准错误）
正确样本 confidence 0.66 vs 错误样本 0.67——错误样本置信度反而略高。当前 confidence 是评分的单调函数，而非"证据一致性"的函数。300489光智科技置信0.83却反向+6.25%、RM0菜粕置信0.71反向+5.71%，高置信度集中堆积在背离样本上，是典型的 miscalibration。

### 模式C：中性信号被"软看空"污染 + 灰色地带分辨率盲区
中性信号占65.4%（125/191），贡献46条错误。技术面评分集中在47-61的"灰色地带"，恰是信号映射函数的分辨率盲区。残留 override 权重把轻微负背离放大为方向性判断（EB0苯乙烯技术61偏多却给中性，收益-6.62%）。同时，辩论一边倒（如3:0看跌）实为空头拥挤的反向信号——RM0菜粕、300489光智科技均属此类逼空。

## 3. 成功信号特征

成功样本高度集中在 "看空 + 高置信(0.82) + 评分41.8 + 无背离" 这一簇（株冶、盛和、长电、卓胜微四例评分完全一致41.8）。共性：

- 技术面与多空辩论方向一致（无背离），证据自洽；
- 评分落在明确的 bearish 区间，而非边界模糊区；
- 置信度0.82对应"证据一致"而非"评分极端"；
- 成功样本整体评分偏低（47.96 vs 失败49.38）、辩论更偏空（-1.35 vs -1.00）。

关键结论：当前因子体系在识别看空机会上更有效，看多识别能力严重不足。唯一有效看多样本300394天孚通信评分59.1，显著高于其他看多样本——说明看多需要更高的评分门槛才成立，这正是 optimizer 应自动学到的非线性映射。

## 4. 数据驱动改进建议（禁止硬编码）

### 4.1 扩展历史数据仓库
- 积累30-60日 tick-level 数据：引入日内 TickFlow（分钟级成交量分布、大单净流入、盘口失衡）作为技术面前置校验，缓解日频滞后。
- 建立背离度时间序列：将 `fundamental_technical_divergence` 按日滚动计算，生成 z-score 和分位数，作为连续特征输入 optimizer。
- 配对入库：把每日 `feature_snapshot`（含 fund-tech divergence、sentiment-macro divergence、debate净得分、confidence、weighted_score）与真实收益标签配对，积累≥60个交易日。

### 4.2 新增可学习因子特征（供 optimizer 学习权重）
- `divergence_zscore`：fund-tech 背离的滚动标准化值
- `divergence_sign_x_magnitude`：背离的符号×幅度作为独立特征（而非仅诊断字段）
- `tech_score_bucket_entropy`：技术面评分在42-59区间的分布熵
- `debate_net_score_x_divergence`：辩论净得分与背离度的交互项
- `debate_score_variance`：辩论得分方差（方差过小=拥挤=反向）
- `confidence_calibration_error`：历史置信度与实际胜率的滚动偏差
- `signal_type_frequency`：各信号类型历史出现频率

### 4.3 需重新学习的权重与映射
- 技术面因子分段权重：42-59区间对方向区分度接近随机，optimizer 应学习该区间降权。
- 置信度重校准：把 confidence 从"评分函数"改为"证据一致性函数"的可学习输出，以历史 reliability diagram 为优化目标。
- 辩论净得分非线性变换：引入分段或交互项，让 optimizer 学习"极端一致=反向"的映射。
- 样本权重机制：对近期错误样本（尤其看多簇）赋予更高采样权重，衰减率由 optimizer 通过时间衰减核自动决定。

### 4.4 可证伪 Thesis Breakers（每个错误方向均需具备）
- 看多 thesis breaker：该标的近3日已涨停≥1次 / 龙虎榜出现游资席位 / 换手率异常放大 / 北向连续净流出 / 技术面跌破前低 → 立即重估，情绪透支。
- 看空 thesis breaker：辩论看跌得分≥3且无分歧 / 融券余额骤增 / 空头拥挤度指标触顶 → 逼空风险，重新评估。
