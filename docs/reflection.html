A股归因： 钢铁/有色板块（华菱钢铁、首钢股份、安泰科技、东方钽业）在2026年8月出现基本面（供给侧改革、限产政策）与技术面（前期超跌、均线空头排列）的典型背离。A股政策驱动的周期股行情往往先于技术面反转启动——政策信号（如限产令、收储公告）传导至基本面预期只需数日，但技术指标（均线、MACD）滞后数周。当前系统在技术面偏弱时压制多头信号，恰好错过了政策驱动的反转起点。

可证伪的Thesis Breakers： 若背离度>10的样本中，后续5日成交量未放大至20日均量1.5倍以上，且板块内涨停家数未增加，则"政策驱动反转"假设不成立，应回归技术面主导逻辑。监控触发器：板块成交额环比变化率、涨停/跌停家数比。

可证伪的Thesis Breakers： 若看空信号中，北向资金持股比例未在随后5日内下降，且两融余额未减少，则"高置信看空"假设不成立。监控触发器：北向资金日度净流入、两融余额变化率。

## 4. 数据驱动改进建议

### 4.1 扩展历史数据维度

| 数据类别 | 具体内容 | 解决的问题 |
|---------|---------|----------|
| 政策事件库 | 国务院/部委/交易所政策公告时间戳、政策类型标签（供给侧/产业/监管/货币）、政策力度评级 | 捕捉A股政策市特征，量化政策对板块的冲击方向与持续时间 |
| 北向资金个股持仓 | 日频北向持股比例变化、连续净买入/卖出天数 | 验证"外资逆势吸筹"假设，作为多空辩论的独立证据 |
| 两融余额个股数据 | 融资余额变化率、融券余额变化率、融资买入占比 | 反映杠杆资金风险偏好，判断看空信号是否被杠杆资金证伪 |
| 龙虎榜数据 | 机构席位净买入/卖出、营业部席位活跃度、上榜原因 | 识别散户羊群效应与机构逆势行为 |
| 涨停/跌停统计 | 每日涨停家数、炸板率、连板高度、跌停家数 | 衡量市场情绪温度，判断中性信号是否应偏向方向性 |
| 行业轮动数据 | 申万一级行业日度涨跌排名、行业资金净流入排名 | 判断标的是否处于政策/资金关注的行业风口 |

### 4.2 新增因子特征

| 因子名称 | 计算方式 | 预期作用 |
|---------|---------|----------|
| divergence_penalty_score | 基于fund-tech背离度、sentiment-tech背离度、macro-tech背离度的加权综合 | 让优化器学习"背离度多大时应降低置信度"而非硬编码拦截 |
| policy_event_proximity | 距最近相关政策事件的天数（指数衰减） | 捕捉政策事件对板块的短期冲击窗口 |
| northbound_flow_trend | 北向资金连续N日净买入/卖出强度 | 作为独立于多空辩论的资金面证据 |
| retail_sentiment_index | 基于龙虎榜营业部活跃度、涨停炸板率、换手率的综合指标 | 量化散户情绪，解释"辩论看跌但市场看涨"的背离 |
| debate_confidence_gap | 多空辩论中胜方得分与败方得分的差距（而非仅看净得分方向） | 区分"勉强胜出"与"压倒性胜出"，优化置信度校准 |
| volume_price_divergence | 价格变动与成交量变动的背离程度 | 识别"缩量上涨/放量下跌"等A股特有量价信号 |

### 4.3 让优化器自动学习的映射关系

- 背离度→置信度映射：让 parameter_optimizer 学习"背离度X时置信度应调整为Y"的连续函数，而非设定背离度阈值。
- 多空辩论得分→信号映射：当前辩论净得分0.02（错误）vs 0.58（正确）的差异说明辩论得分到信号的映射需要重新校准，但应通过优化器学习而非人工调整。
- 分项得分权重自适应：当前错误样本基本面得分更高但预测错误，说明基本面权重可能过高或基本面与技术面的交互项未被建模。应让优化器学习"在技术面弱势时，基本面得分的边际贡献应如何衰减"。
