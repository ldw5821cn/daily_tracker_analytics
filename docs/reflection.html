## 1. 一句话总结

四因子常数化致决策维度坍缩，模型在轮动市中把"资金未定价"误判为"无方向"，中性桶沦为垃圾桶。

## 2. 主要错误模式

### 模式A：因子维度坍缩 + 中性桶垃圾桶化（结构性错误，占错误主体）
- 新闻情绪/基本面/宏观/市场上下文四项因子零方差（50.0/50.0/50.8/50.0），模型实际仅靠 `tech_score + debate_net` 两个弱信号决策。
- 中性信号占 74.9%（143条），错误率 51.75%，接近随机；optimizer 决策边界塌缩到中性区，把方向不明确样本全部塞入。
- 本质：不是权重问题，是有效特征维度不足——4/6 维度无信息量，剩余维度无法支撑方向判断。

### 模式B：滞后技术面 + 高置信度 = 脉冲行情反向指标
- 688220/600584/688018 三条：tech=44、辩论 0:3 看跌、置信 0.82、评分 42.1 → 实际 +7.6%~+11.2%。
- 同板块（半导体设计/封测）同日同向大涨，暴露板块beta因子完全缺失。
- 置信度均值正确/错误样本均为 0.66，零信息量；高置信度(0.82)反而错得最狠——置信度与评分尺度解耦。
- A股解释：轮动市中游资打板脉冲启动前，滞后均线/动量必然给低分；龙虎榜、封单量、板块涨停家数等领先信号缺失。

### 模式C：背离度符号误用 + 宏观"伪中性"
- 错误样本 divergence 均值 -3.16（正确 -2.52），看多错误样本达 -14.00——深度负背离（基本面>>技术面）在A股常对应政策/资金突变，模型却按趋势延续处理。
- 原油 -11.97%、焦煤 -7.98% 均为"观望+宏观中性50.8"，实为宏观正在定价方向性事件（地产/能耗/OPEC+），模型把"数据缺失"误判为"无方向"。

## 3. 成功信号特征

- 评分与置信同向且中等偏高：看多样本评分 58.8~59.3、置信 0.63~0.73，收益 +2% 级别。
- 分项一致性高：成功样本 divergence 接近 0（-2.52 vs 错误 -3.16），分项无剧烈冲突。
- 板块聚集：天孚/光迅/有研新材/振华科技全部集中在光通信/半导体材料——存在局部主线（AI算力/光模块），但模型未识别为 regime 主线，仅"碰巧"评分略高。
- 关键局限：成功样本收益幅度小（+1.46%~+2.52%），失败样本幅度大（±7%~±12%）——模型只能捕捉小波动、系统性错失大波动，因缺少政策/资金类大波动驱动因子。

## 4. 数据驱动改进建议（供 parameter_optimizer 自动学习）

原则：只喂特征与标签，不设阈值、不设方向否决门。

1. 修复常数因子：接入真实新闻情绪/基本面/宏观数据源，恢复四因子方差，否则优化器无参数可学。
2. 新增交互特征入 feature_snapshot：
- `fund_tech_divergence × tech_score`、`divergence × debate_net`（让优化器学习背离在不同 tech 区间的真实方向）
- `debate_net` 与 `debate_total` 分离（0:3 与 1:1 净分相同但含义不同）
3. 新增板块因子：申万一级/二级行业 one-hot 或 embedding + 板块当日涨跌幅 + 板块内涨停家数，让优化器学习板块beta权重。
4. 新增A股特色资金因子：`limit_up_count`、`limit_down_count`、`broken_board_rate`（炸板率）、`northbound_net_flow`、`margin_balance_change`、`option_pcr`。
5. 置信度重构：将 confidence 改为可学习输出（isotonic 校准层），用历史 (confidence, 实际正确) 训练，替代固定公式。
6. 扩展标签仓库：积累 60~90 天、500+ 条样本，标注 T+1/T+3/T+5 多周期收益，构建 `(feature_snapshot, forward_return)` 配对数据集。
7. 样本权重：时间衰减 + 错误样本重采样，优先修正当前市态偏差，同时保留历史样本防过拟合。

## 5. 策略回测建议

当前 Regime 判定：震荡轮动市（指数震荡、结构剧烈分化、情绪脉冲主导）。

- 趋势跟随类策略不适用（宏观 neutral、信号分布塌缩、无单边主线）。
- 优先采用"板块动量 + 个股相对强弱"策略：多因子中3个已失效，板块beta是当前唯一被验证有效的核心变量（成功/失败样本均高度板块聚集）。
- 辅助采用均值回归/中性对冲策略：对方向判断依赖低，适配"中性标的波动最大"的轮动市特征。
- 建议对6种策略做 A/B 回测，用真实收益标签让 optimizer 自动选择，而非人工指定。
- 权重方向：降低 confidence 权重（零信息量），提升 divergence 与分项一致性权重，由 optimizer 在回测中搜索。

## 6. 今日操作建议（明日预测）

1. 对"高置信度 + 低评分 + 中性信号"组合保持警惕：conf>0.8 且评分<45 的样本历史错误率显著偏高，建议通过权重学习降低其仓位权重（非硬拦截）。Thesis breaker：若该组合所在板块当日出现板块指数放量上涨或北向净流入同向确认，则thesis失效，应重估为板块动量信号。

2. 对深度背离样本（|divergence|>10）触发 thesis 重估：当前看多错误样本 divergence 达 -14.00，说明深度负背离在A股常对应政策/资金突变。Thesis breaker：若北向资金/两融无同向确认，则背离方向映射失效，需重新评估；若有同向确认，则维持原方向。

3. 对商品/宏观敏感标的（原油、焦煤等） ：宏观分项 50.8 为"伪中性"，建议在 optimizer 校准前降低此类标的的观望信号权重。Thesis breaker：若宏观数据源接入后该分项脱离50区间，则伪中性假设失效。

## 7. 需要新增/改进的数据源或因子

| 类别 | 新增数据源/因子 | 用途 |
|---|---|---|
| 资金面 | 北向净流入、两融余额变化、龙虎榜席位、涨停封单量 | 捕捉增量资金确认，解释"看多信号反而准" |
| 情绪面 | 涨停家数、跌停家数、连板高度、炸板率、封板率、option PCR | 构建 regime 温度计，区分"中性被选中/被抛弃" |
| 板块面 | 申万行业标签、板块当日涨跌幅、板块内涨停家数 | 捕捉板块beta（当前核心缺失变量） |
| 宏观面 | 真实宏观数据源（政策事件、地产/能耗/OPEC+） | 修复宏观"伪中性"，区分"数据缺失"与"无方向" |
| 背离面 | `fund_tech_divergence × tech_score`、`divergence × debate_net` 交互项 | 让优化器学习背离的真实方向映射 |
| 辩论面 | `debate_net` 与 `debate_total` 分离 | 区分 0:3 与 1:1 的不同含义 |
| 标签面 | T+1/T+3/T+5 多周期真实收益，500+ 样本 | 支撑 optimizer 稳定学习 |
| 校准面 | `confidence_calibration_residual`（历史同置信区间实际胜率） | 重构置信度模块 |
