## 4. 数据驱动改进建议（拒绝硬编码）
- 管道健康因子：将各 agent 返回延迟、成功率、观点方差作为特征喂给 parameter_optimizer，让其自动学习"信息不完整时应下调多少置信度"。

- regime 条件化权重：让优化器按波动率、量能、政策事件密度自动调整各因子权重，权重由历史样本回归得到，不落固定数值。
