## 4. 数据驱动改进建议

### 4.1 新增历史数据维度

| 数据类别 | 具体字段 | 用途 |
|----------|----------|------|
| 政策事件数据 | 国务院/部委政策发文时间戳、行业扶持/监管文件、五年规划相关标的映射 | 捕捉A股政策市特征，量化政策事件对板块的短期冲击 |
| 资金流向数据 | 北向资金个股持仓变动、两融余额日度变化、龙虎榜机构/游资席位 | 刻画A股增量资金行为，区分机构与散户主导的行情 |
| 微观结构数据 | 涨停封单量/成交额比、炸板率、连板高度、换手率分位数 | 捕捉散户情绪与市场微观结构变化 |
| 期权/衍生品数据 | 50ETF期权PCR、隐含波动率曲面 | 刻画机构对冲需求与市场尾部风险预期 |

### 4.2 新增因子/特征

| 因子名称 | 计算方式 | 假设 |
|----------|----------|------|
| policy_event_strength | 近期（30日）该标的所属行业政策事件数量×事件影响方向 | 政策事件是A股板块轮动的主要驱动力之一 |
| northbound_flow_zscore | 北向资金个股净流入的20日Z-score | 外资在A股的定价权逐步提升，北向资金持续流入的标的后续跑赢概率较高 |
| retail_sentiment_score | 基于换手率分位数、龙虎榜散户席位占比、互动易/股吧热度构建 | 散户情绪过热时短期回调概率大，情绪冰点时反弹概率大 |
| divergence_direction | 记录fund-tech背离的方向（fund>tech vs tech>fund）及背离持续时间 | 不同方向的背离在不同市场环境下含义不同，让优化器自动学习 |
| limit_up_effect | 该股近期是否涨停、涨停后次日溢价率、板块涨停家数 | 涨停制度对A股短期收益有显著影响 |

### 4.3 让 parameter_optimizer 自动学习的参数

- 宏观信号对最终得分的权重映射：当前宏观偏空时系统过度保守，应让优化器学习"宏观信号在不同市场环境下的边际影响"
- 背离度与信号方向的关系：让优化器学习"背离度在什么范围内应抑制信号，在什么范围内应增强信号"
- 分项得分的非线性变换：当前分项得分线性加权，但可能非线性关系更合理（如基本面>70分时边际影响递增）
