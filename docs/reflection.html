## 2. 主要错误模式

模式一：debate 强空头证据被"中性化"吞没（占比最高）

证伪方式：监控"debate 净得分 ≤ -2 且 tech_score < 50"组合的次日收益分布——若该组合持续跑输（当前 5 个案例全部大跌，已可初步确认），则"debate 空头 + 技术中性 ⇒ 中性"这一映射本身被证伪，应交由 optimizer 重学该联合特征的信号映射，而非继续由 score 中位数决定。

模式二：score 分布塌陷，信号实质上是"猜 50 上下"

失败样本评分 42.3-52.4，成功样本看空也只有 21-36、看多 78-94——系统只在信号远离 50 时才对，贴近 50 的信号（占大多数）几乎全是噪音。结合历史知识库 `tech_score_distribution_bias`（大量 42-45 分），技术面公式输出存在系统性压缩，且 bandit 中性区间可能过宽。
