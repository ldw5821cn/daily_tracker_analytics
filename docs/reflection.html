## 4. 数据驱动改进建议

### 4.1 历史数据扩展

| 数据类别 | 具体内容 | 用途 |
|---------|---------|------|
| 龙虎榜数据 | 每日龙虎榜席位明细（机构/游资/散户）、净买入额、上榜原因 | 识别资金合力方向，捕捉题材启动信号 |
| 涨停/跌停统计 | 每日涨停家数、炸板率、连板高度、涨停封单额/流通市值比 | 衡量市场情绪温度，判断题材持续性 |
| 北向资金明细 | 分行业/个股的北向持仓变动、净买入TOP20 | 反映外资增量资金偏好 |
| 两融余额 | 融资余额变动、融资买入额/成交额比、融券余额 | 衡量杠杆资金风险偏好 |
| 政策事件日历 | 国务院/部委政策发布、行业监管变化、产业规划出台 | 捕捉政策驱动型行情 |
| 题材/概念板块数据 | 概念板块涨跌幅排名、板块内涨停家数、板块轮动节奏 | 识别市场主线，避免"中性"误判 |

| 因子名称 | 计算方式 | 预期作用 |

| 市场情绪温度计 | 涨停家数/跌停家数比 + 炸板率 + 连板高度 | 判断市场风险偏好，辅助中性/方向信号切换 |
| 政策敏感度因子 | 标的所属行业近30日政策事件数量及方向（利好/利空） | 捕捉政策市特征 |
