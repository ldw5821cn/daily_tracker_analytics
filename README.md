# 📈 每日股票分析系统

> 一个自主进化、每日复盘、持续优化的投资决策系统。

---

## 🧭 定位

**从每一次交易中学习。每一天都在进化。**

这不是一个静态的投资策略——而是一个**自我学习的决策系统**。它不依附任何单一流派或基金经理，融合了多种经过验证的框架，并通过每日反思持续优化。

---

## 🔄 每日运行周期

```
09:00 开盘 ──→ 11:30 午间 ──→ 15:00 收盘 ──→ 15:30 盘后全链路 ⭐
                                                       │
               ┌───────────────────────────────────────┼───────────────────────┐
               ▼                                       ▼                       ▼
        全A股扫描(3953只)                         每日复盘反思              雪球组合更新
        6维评分+板块分散                         错误模式识别              持仓净值+收益
        Top10推荐                                知识库进化                Pages部署
```

### 调仓时机

| 频率 | 时间 | 操作 |
|------|------|------|
| **每日** | 15:30 | 全A股扫描 → 打分 → 反思 → 更新Pages → 微信推送 |
| **每周** | 周一 08:00 | ⭐ **全量调仓**：全A股扫描 → Top10 → 雪球组合一键调仓 |

**注意：** 雪球组合只在**每周一早上08:00**进行实际调仓（买入/卖出）。每日15:30的流水线是分析+反思，不操作持仓。这样避免频繁交易带来的滑点和T+1规则限制。

## 🔐 环境与密钥配置

所有 API 密钥和私有配置**仅存于本地**，通过 `.env` 文件管理（已加入 `.gitignore`，不会提交到 GitHub）。

### 快速开始

```bash
# 1. 复制模板
cp .env.example .env

# 2. 填入真实密钥（以下两项必须）
#    TICKFLOW_API_KEY — 实时行情数据
#    TUSHARE_TOKEN   — A股股票池
vim .env
```

### 可用环境变量

| 变量 | 必填 | 说明 | 获取方式 |
|------|------|------|---------|
| `TICKFLOW_API_KEY` | ✅ | TickFlow 行情 API key | [tickflow.org](https://tickflow.org) 注册 |
| `TUSHARE_TOKEN` | ✅ | Tushare Pro token（股票池/日线） | [tushare.pro](https://tushare.pro) 获取 |
| `XUEQIU_GID` | ✅ | 雪球组合 GID | 组合页面URL中获取 |
| `HERMES_WEIXIN_TOKEN` | ❌ | 微信推送 token（Hermes） | Hermes Web UI 配置 |

### 安全机制

- **优先顺序**：代码优先读 `.env` → 找不到则 fallback 到 `etf_tracker/config.json`
- **密钥隔离**：`etf_tracker/config.json` 包含 ETF 列表/板块配置等非敏感设置（可正常提交 Git），API key 字段已全部清空
- **雪球 cookies**：存放在 `multi_agent/data/xueqiu_config.json`（`data/` 已在 `.gitignore` 中）
- **数据文件**：`data/`、`.reports/`、`logs/` 目录均被 `.gitignore` 忽略，不会泄露持仓数据
- **硬编码检查**：项目中所有 API key、token、密码均已去除硬编码值，改为环境变量读取

### 新增密钥

```bash
echo "YOUR_NEW_KEY=your_value" >> .env
```
然后在 Python 代码中用 `os.environ.get('YOUR_NEW_KEY')` 读取。

## 📊 评分体系 (v2)

6维评分 + 风控扣分 + 板块分散选股：

| 维度 | 权重 | 说明 |
|------|------|------|
| 📈 动量趋势 | 30 | 温和上涨优先，>5%后递减，涨停扣分（追强不追高） |
| 💰 成交验证 | 20 | 流动性验证，>50亿最优 |
| 📐 估值安全 | 15 | PE 10-25最优，亏损股扣分 |
| 🏢 市值弹性 | 15 | 30-80亿中小盘最优 |
| 🔄 换手质量 | 10 | 3-10%健康换手，>20%扣分 |
| 💵 价格舒适 | 10 | 5-20元最佳区间 |
| ⚠️ 风控扣分 | -5~0 | 涨停-3 / 换手>25%-2 / 亏损-2 |

**板块分散**：每板块最多2只，至少覆盖3个不同板块。

### 大师思维加成

评分后叠加8位投资大师的思维框架调整（`skills/master_mindset.py`）：

| 大师 | 调整逻辑 | 调整幅度 |
|------|---------|---------|
| 🟢 **巴菲特** 护城河 | 品牌+机构集中+稳定龙头 → 加分 | +1~3分 |
| 🟠 **利弗莫尔** 关键点 | 前高/平台突破 + 上升趋势 → 加分 | +2~3分 |
| 🔴 **炒股养家** 情绪周期 | 主力热点板块龙头 → 加分 | +1~2分 |
| ⚪ **格雷厄姆** 安全边际 | PE<15 + PB合理 → 加分 | +1~3分 |

每日反思时系统会从8位大师视角自动生成12条检查清单，回答的是「**巴菲特/利弗莫尔/炒股养家会怎么看今天的操作？**」

## 🧠 自我进化

```
每日扫描 → 评分 → 板块分散选股 → 组合更新
    ↓                                        ↓
知识库 ← 错误模式识别 ← 每日复盘反思 ← 收益评估
    ↓
策略权重微调 → 下一次更优决策
```

系统维护一个不断增长的知识库 `data/strategy_knowledge.json`：
- 板块胜率（推荐的板块实际表现如何）
- 错误模式（为什么亏损，如何避免）
- 持仓周期（持有时长与收益的关系）
